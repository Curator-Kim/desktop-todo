# 桌面待办

一款轻量的 Windows 托盘待办便签。主便签只显示标题和截止时间，任务详情使用即时富文本编辑，支持图片、提醒和完成记录。

主便签可以随时拖动非按钮区域来移动，拖动窗口边缘缩放；下次启动会恢复位置和大小。设置面板是独立窗口，移动它不会影响便签。设置中支持自选背景颜色或本地图片、调整透明度、恢复默认设置，以及检测并自动安装经签名验证的新版本。恢复默认设置或程序更新均不会删除任务和完成记录。

- **数据位置**：在设置中选择目录并迁移。旧版数据会在首次启动时自动导入；迁移完成后旧目录仍保留一份副本，目标目录已有数据时不会覆盖。
- **截止时间**：点击日历图标选择日期与时间，选中的时间会随任务一起保存；「确认时间」可收起选择面板。
- **已完成任务**：从便签上的历史图标或托盘菜单打开独立窗口，可恢复或删除记录。

## 开发

```powershell
npm install
npm run desktop:dev
```

## 打包

```powershell
npm run desktop:build
```

安装包会生成在 `src-tauri/target/release/bundle`。

发布新版本的签名与上传步骤见 [RELEASING.md](RELEASING.md)。v0.1.4 及更早版本需要手动安装一次新版本，之后安装版才能使用自动更新。
