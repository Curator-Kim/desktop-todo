# 桌面待办

一款轻量的 Windows 托盘待办便签。主便签只显示标题和截止时间，任务详情使用即时富文本编辑，支持图片、提醒和完成记录。

主便签可以随时拖动非按钮区域来移动，拖动窗口边缘缩放；下次启动会恢复位置和大小。设置面板是独立窗口，移动它不会影响便签。设置中支持自选背景颜色或本地图片、调整透明度、恢复默认设置，以及检测并自动安装经签名验证的新版本。恢复默认设置或程序更新均不会删除任务和完成记录。

启动时会自动显示主便签，设置与完成记录窗口保持隐藏。手动关闭便签后，程序继续在托盘运行，点击托盘图标可重新显示。

- **数据位置**：在设置中选择目录并迁移。旧版数据会在首次启动时自动导入；迁移完成后旧目录仍保留一份副本，目标目录已有数据时不会覆盖。
- **截止时间**：点击日期和时间输入框选择截止时间，选中的时间会自动保存；「确认时间」可收起选择面板。
- **已完成任务**：从便签上的历史图标或托盘菜单打开独立窗口，可恢复或删除记录。
- **日历视图**：点击便签顶部的日历／列表按钮切换。月历按本地截止日期分组，可翻月或回到今天；视图选择会自动记住。
- **融入桌面**：点击顶部的「融入桌面」按钮，将便签放到桌面图标后并隐藏背景和操作按钮。此时保留窗口的实际大小以及文字、图标、任务行的显示比例，避免不同缩放比例的副屏出现内容缩小。鼠标操作穿透，左键点击系统托盘中的桌面待办图标即可恢复，并重新启用正常的跨屏缩放。此功能依赖 Windows 桌面层，找不到兼容桌面层时会提示失败。

## 开发

```powershell
npm install
npm run desktop:dev
```

启动与托盘恢复回归测试（使用临时浏览器数据，不读取用户待办）：

```powershell
cargo run --manifest-path src-tauri/Cargo.toml --example startup_smoke --release --features tauri/custom-protocol
```

## 打包

```powershell
npm run desktop:build
```

安装包会生成在 `src-tauri/target/release/bundle`。

发布新版本的签名与上传步骤见 [RELEASING.md](RELEASING.md)。v0.1.4 及更早版本需要手动安装一次新版本，之后安装版才能使用自动更新。
